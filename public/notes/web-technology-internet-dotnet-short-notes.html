Internet, WWW and Web Architecture

Internet, intranet and the World Wide Web

Internet: a worldwide network of interconnected networks communicating through the TCP/IP protocol suite. It is the underlying infrastructure, not a single website.

World Wide Web (WWW): a system of interlinked documents and resources identified by URLs and commonly accessed through HTTP/HTTPS. The Web is one service that uses the Internet; email, file transfer and other services also use the Internet.

Intranet: a private network using Internet technologies within an organisation. An extranet gives authorised external users limited access to selected organisational resources.

Web pages, websites and browsers

  • Web page: an individual document/resource, usually delivered as HTML.
  • Website: a collection of related pages and resources, usually organised under a domain name.
  • Home page: the main entry page of a website.
  • Web browser: client software that requests, interprets and displays web resources. Examples include Chrome, Firefox, Edge, Safari and Opera.
  • Search engine: a service that crawls/indexes content and helps users retrieve information. It is not a browser or a web server.
  • Web server: server software (and often the host machine) that accepts HTTP requests and returns resources or application responses. Examples include Apache HTTP Server and Nginx.

Client–server architecture

A browser/client sends a request to a server. The server may return a static file or execute application code, query a database and return a generated response. The browser renders the response. A web application may therefore contain a browser-based front end, an application/API layer and a database layer.

Website planning and online communication

  • Wireframe: a rough structural plan of a page/site showing where content, navigation and controls will appear before final colours, typography and imagery are applied.
  • Navigation: menus, links and information architecture that let users move between pages.
  • Browsing/surfing: moving between web pages and websites through links or navigation.
  • Netiquette: accepted online communication etiquette—be respectful, avoid spam and personal attacks, protect private information and do not use all capitals as shouting.
  • Real-time communication: instant messaging, live chat, voice/video calls and conferencing.
  • Emoticons/smileys: text or pictorial symbols that help convey tone in online messages.

Publishing a website

  1. Plan content and navigation; create and test HTML/CSS/JavaScript assets.
  2. Choose a domain name and hosting/server environment.
  3. Upload/deploy files or publish the application; configure DNS records to point the domain to the service.
  4. Enable HTTPS, test links/forms and responsive behaviour, check accessibility and performance.
  5. Monitor, back up and update the website.
Exam focus: Internet vs WWW; browser vs search engine vs server; web page vs website; client–server flow; wireframe; netiquette; real-time communication.

  1. PYQ #2 · 2021 · DSSSB - Computer Science

    A collection of web pages is known as ____.

    1. A. Website
    2. B. Web server
    3. C. Web world
    4. D. Web tool

    Correct answer: A. Website

    Explanation (workbook): Core Concept: A website is a collection of related web pages that are hosted on a web server and can be accessed through the Internet.

    Why other options are incorrect: A web server is a system that hosts and delivers web content. 'Web world' and 'Web tool' are not standard terms for a collection of web pages.

  2. PYQ #8 · 2023 · DSSSB TGT Computer Science

    ________ are a database applications' universal front end that connects to the back end via the internet.

    1. A. Web browsers
    2. B. Web server
    3. C. Software programs
    4. D. Web application

    Correct answer: A. Web browsers

    Explanation (workbook): Core Concept: Web browsers are client-side applications that allow users to access and interact with web content, including web-based database applications. They serve as the universal front end, sending requests to a web server (which then communicates with the database backend) and displaying the results to the user, all typically over the internet using protocols like HTTP.

    Why other options are incorrect: A web server is a backend component that serves web pages and handles requests, acting as an intermediary between the browser and the database, not the front end itself. 'Software programs' is too general. A web application is the server-side logic and content that the browser interacts with, but the browser itself is the 'universal front end'.

  3. PYQ #12 · 2021 · DSSSB TGT Computer Science

    A ______ prepares a rough outline of what a website will look like once it is built.

    1. A. Wireframe
    2. B. Web plows
    3. C. Wire falls
    4. D. Web frames

    Correct answer: A. Wireframe

    Explanation (workbook): Core Concept: A wireframe is a low-fidelity, skeletal visual guide that represents the basic structure and layout of a website or application. It outlines the content and functionality on a page, focusing on space allocation and prioritization of content, without considering visual design elements like colors or typography. It serves as a blueprint before detailed design begins.

    Why other options are incorrect: The other options, 'Web plows', 'Wire falls', and 'Web frames', are not standard or recognized terms in web design or user experience (UX) for describing a rough outline of a website. 'Web frames' might vaguely refer to HTML framesets (an outdated web technology) but not a design blueprint.

  5. PYQ #50 · 2021 · DSSSB TGT Computer Science

    Which of the following statement(s) is/are true about wire framing of website? I. Showing which content will appear on which page II. Showing navigator between pages

    1. A. Only I
    2. B. Neither I nor II
    3. C. Both I and II
    4. D. Only II

    Correct answer: C. Both I and II

    Explanation (workbook): Core Concept: Both statements are true about wireframing a website. Wireframes are visual guides that represent the skeletal framework of a website. They are used to show which content will appear on which page (I) and to illustrate the navigation scheme and how users will move between pages (II), focusing on layout and functionality rather than visual design.

    Why other options are incorrect: Options A, B, and D are incorrect because wireframing encompasses both aspects: defining content placement on pages and outlining the navigation structure. Omitting either of these aspects would provide an incomplete understanding of wireframing's purpose.

  6. PYQ #65 · 2023 · DSSSB TGT Computer Science

    Which service is NOT provided by web servers?

    1. A. Serving web pages
    2. B. Resource sharing
    3. C. Server side scripting
    4. D. Running gateway programs

    Correct answer: B. Resource sharing

    Explanation (workbook): Core Concept: Web servers are primarily designed to serve web content (like HTML pages, images), execute server-side scripts (e.g., PHP, Python), and run gateway programs (like CGI scripts) to generate dynamic content. Resource sharing, in the context of sharing files, printers, or other network resources among users, is typically a function of a file server or a general-purpose network server, not a dedicated web server.

    Why other options are incorrect: Serving web pages is the fundamental purpose of a web server. Server-side scripting and running gateway programs are common functionalities that enable web servers to deliver dynamic content and interact with other applications or databases. These are all core services provided by web servers.
