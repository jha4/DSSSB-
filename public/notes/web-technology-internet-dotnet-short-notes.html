Web Technology, Front-End, Internet Programming and .NET — Complete Notes

Coverage: Internet architecture, browsers and servers, URL/domain/hosting, HTML, CSS, JavaScript, XML, AJAX, web services, MVC and .NET fundamentals.

1. Internet and World Wide Web

The Internet is a global interconnection of networks using the Internet protocol suite. The World Wide Web is an information system using linked resources and web protocols over the Internet; the Web is not the entire Internet.

  • Client: requests a resource/service. Server: responds and provides resources.
  • Browser: client software retrieving and rendering web content. Web server: software/system serving HTTP responses.
  • URL: identifies a resource and may contain scheme, host, port, path, query and fragment. DNS resolves domain names to network addresses.
  • Hosting: infrastructure that makes a site reachable. A proxy server intermediates requests between clients and servers.

2. HTML

HTML (HyperText Markup Language) structures web documents. Elements use tags and may have attributes. A typical document contains doctype, html, head and body sections.

  • Headings h1–h6, paragraphs p, links a, images img, lists ul/ol/li and tables table/tr/th/td structure content.
  • Forms collect input through form, label, input, select, textarea and button. Common input types include text, password, email, number, checkbox, radio and submit.
  • Semantic elements such as header, nav, main, section, article, aside and footer describe page roles.
  • HTML describes structure; CSS controls presentation; JavaScript adds behaviour.

3. CSS and layout

CSS (Cascading Style Sheets) controls visual presentation. The cascade resolves competing declarations using origin, importance, specificity and source order.

  • Box model: content, padding, border and margin. With content-box sizing, declared width excludes padding and border; border-box includes them.
  • Selectors: element, class, ID, attribute, pseudo-class and descendant/child selectors.
  • Layout: normal flow, display, position, Flexbox and Grid. Responsive design adapts layout to viewport/device constraints.

4. JavaScript

  • JavaScript is used in browsers and server runtimes. let and const are block-scoped; var is function-scoped. Prefer strict equality (===) when coercion is not intended.
  • Function: reusable callable code. A callback is a function supplied to another function to run later or in response to an event.
  • DOM: object model of the document. Scripts select elements, read/change properties and respond to events.
  • Event handling: listeners respond to click, input, submit and other events. Client-side validation improves usability but must be repeated server-side because client code can be bypassed.

5. XML, AJAX and web services

  • XML: extensible markup language for structured data. It is case-sensitive and must be well-formed with proper nesting and one root element.
  • DTD: defines permitted XML structure and entities; XML Schema (XSD) offers richer typing and constraints.
  • AJAX: browser technique for asynchronous requests and partial page updates; it is not a programming language.
  • Web service: machine-to-machine interface. REST commonly uses HTTP methods and resource-oriented URLs; SOAP uses structured XML messaging and related standards.

6. MVC and .NET

  • MVC: Model represents data/business rules, View presents output, Controller handles input and coordinates actions.
  • .NET: development platform with runtime, libraries and language support. C# is a common .NET language.
  • ASP.NET: framework for web applications and APIs. Older ASP.NET Web Forms used server controls and postbacks; modern ASP.NET Core has a different architecture.
  • Java applets are obsolete browser technology; treat applet questions as historical facts, not current web practice.

7. Exam traps

  • Internet is infrastructure; WWW is a service on it.
  • HTML structures, CSS styles, JavaScript adds behaviour.
  • AJAX is a technique, not a language or database. Client-side validation is not a security boundary.

Proxy servers, publishing and browser developer tools

  • Proxy server: an intermediary between a client and another server. A forward proxy acts for clients (for example, policy enforcement, filtering or caching); a reverse proxy sits in front of origin servers and can provide TLS termination, load balancing, caching and request routing.
  • Publishing information: prepare and validate content, select a domain/hosting environment, upload or deploy site files, configure DNS and HTTPS, test links/forms/responsive behaviour, and maintain/refresh the content. A domain name is not the same as web hosting.
  • Browser developer tools: Elements/Inspector examines and edits the DOM/CSS; Console displays logs and JavaScript errors; Network inspects requests, responses, headers and timing; Sources/Debugger supports breakpoints and step-through; Application/Storage inspects cookies, local storage and related browser data.
  • Front-end tools: code editors, browser devtools, validators, package/build tools and version control support authoring and testing. They do not replace accessibility, security and cross-browser testing.

JavaScript callback: a function passed to another function to be invoked later, often after an event or asynchronous operation. An event handler is a common callback. Promises and async/await are other ways to structure asynchronous work; they do not make a slow operation synchronous.
