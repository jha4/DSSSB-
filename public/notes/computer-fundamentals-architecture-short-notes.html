Computer Fundamentals, IT Basics and Architecture — Complete Notes

Coverage: Computer generations, data representation, input/output, memory, storage, software types, CPU organization, instruction cycle and character encoding.

1. Computer fundamentals

A computer is an electronic programmable system that accepts data, processes it according to instructions, stores results and produces information. Data are raw facts; information is processed data with meaning; knowledge is interpreted understanding used for decisions.

  • Speed: executes operations rapidly. Accuracy: produces correct results when inputs and instructions are correct. Diligence: does not tire. Storage: retains large quantities of data. Versatility: performs different kinds of tasks.
  • Results still depend on program quality, data and system design; a computer does not independently guarantee correctness or judgement.

3. Hardware, software and firmware

  • Hardware: physical components such as CPU, memory, keyboard, monitor and storage.
  • System software: manages hardware and provides a platform; operating systems, device drivers and language translators are examples.
  • Application software: performs user tasks such as word processing, spreadsheets, browsing and accounting.
  • Utility software: maintenance tools such as backup, compression and antivirus utilities.
  • Firmware: software stored in non-volatile memory that controls device-level operations.

4. Input, output and storage devices

Input devices enter data (keyboard, mouse, scanner, microphone, barcode reader). Output devices present results (monitor, printer, speaker, plotter). Touchscreens can perform both functions.

  • Impact printers: print by striking an inked ribbon/mechanism against paper (dot matrix). Non-impact: laser and inkjet.
  • Primary memory: directly accessible by the CPU; includes registers, cache and main memory. Secondary storage: persistent storage such as SSD, HDD and optical media.

Bit is the smallest binary unit; 8 bits = 1 byte. Distinguish decimal SI multiples (kB=1000 bytes) from binary IEC multiples (KiB=1024 bytes) when specified.

6. CPU organization and instruction cycle

  • ALU: arithmetic and logical operations. Control Unit: coordinates execution and control signals.
  • Registers: high-speed CPU storage. Program Counter stores the next instruction address; Instruction Register holds the current instruction; status registers hold flags.
  • Buses: data bus carries data, address bus identifies locations/devices, and control bus carries control/timing signals.

Instruction cycle: fetch, decode, fetch operands if needed, execute, then write back/store. Modern processors overlap stages through pipelining.

7. Character encoding and translators

  • ASCII: original 7-bit character code (128 values); extended variants are not one universal standard.
  • EBCDIC: 8-bit encoding historically associated with IBM mainframes.
  • Unicode: universal character repertoire; UTF-8, UTF-16 and UTF-32 are encoding forms.
  • Compiler: translates a program before execution. Interpreter: executes source/intermediate instructions through an interpreter. Assembler: translates assembly language into machine code.

8. Exam traps

  • RAM is volatile; ROM/flash is non-volatile. Cache is not secondary storage.
  • ALU calculates; Control Unit directs. CPU is not another name for the whole computer.
  • Unicode is a character standard; UTF-8 is an encoding form.
