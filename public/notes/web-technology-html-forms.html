HTML and Forms

HTML document structure

HTML (HyperText Markup Language) is a markup language for structuring web content. It is not a programming language. A typical HTML5 document has a doctype, root <html>, metadata in <head> and visible content in <body>.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Sample page</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Heading</h1>
  <p>A paragraph.</p>
  <a href="about.html">About</a>
  <script src="app.js" defer></script>
</body>
</html>

Comment<!-- comment -->

In older HTML, link and vlink body attributes were used for link and visited-link colours. Modern styling should use CSS pseudo-classes such as a:link, a:visited, a:hover and a:focus. The hr element is a void element; do not treat obsolete presentation attributes as modern HTML requirements.

Forms and controls

A form collects user input. Important elements are <form>, <label>, <input>, <textarea>, <select>, <option> and <button>.

  • Input types include text, password, email, number, date, file, radio, checkbox, submit and reset.
  • name identifies the submitted field; id identifies an element; value is its value.
  • action identifies the processing endpoint; method is commonly GET or POST.
  • Radio buttons in the same named group normally allow one selection; checkboxes allow multiple independent selections.
  • Associate labels with controls using for and matching id.

There is no universal HTML rule limiting a page to a fixed maximum number of forms. If an old MCQ gives a fixed limit, treat it as a source-specific or legacy claim, not a modern HTML standard.

Semantic HTML5, audio and video

Semantic elements describe meaning: <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>, <figure> and <figcaption>. Media can be embedded using <audio controls> and <video controls>, often with nested <source> elements.

High-yield: href, target, h1–h6, td, body/head, HTML comments, form controls, br/hr, img alt/src and semantic HTML5 tags.

    Which of the following parameters is used to create a hyperlink in HTML?

    1. A. Link
    2. B. url
    3. C. Path
    4. D. Href

    Correct answer: D. Href

    Explanation (workbook): Core Concept: In HTML, the `href` attribute (Hypertext Reference) is used within the `<a>` (anchor) tag to specify the URL or path of the linked document or resource. For example, `<a href="destination.html">Link</a>`.

    Why other options are incorrect: 'Link' is the tag itself, not an attribute. 'url' and 'Path' are descriptive terms for the value of the `href` attribute, but not the attribute name itself.
  2. PYQ #16 · 2023 · DSSSB TGT Computer Science

    Which of the following opens the linked document in the windows full body among the target values?

    1. A. _self
    2. B. _top
    3. C. _blank
    4. D. _parent

    Correct answer: B. _top

    Explanation (workbook): Core Concept: In HTML, the `target="_top"` attribute value for an `<a>` tag opens the linked document in the full body of the window, effectively breaking out of any framesets or iframes.

    Why other options are incorrect: `_self` opens the document in the same frame/window (default). `_blank` opens it in a new window or tab. `_parent` opens it in the parent frameset. None of these open the document in the full body of the window, canceling all frames, like `_top` does.
