Quadratic Equations: Roots, Discriminant & Relations

Standard Form: ax2 + bx + c = 0, where a, b, c ∈ ℝ and a ≠ 0.

1. Quadratic Formula (Shridharacharya Formula)

x = (-b ± √(b2 - 4ac)) / (2a),    where Discriminant D = b2 - 4ac

2. Nature of Roots Using Discriminant (D)

Discriminant Value Nature of Roots Graph Position (y = ax2 + bx + c)
D > 0 Two distinct real roots Cuts the x-axis at two distinct points
D = 0 Two equal real roots (-b / 2a) Touches the x-axis at exactly one point
D < 0 No real roots (complex conjugates) Does not touch or cross the x-axis

3. Sum and Product of Roots

If α and β are the roots of ax2 + bx + c = 0:

  • Sum of roots: α + β = -b / a
  • Product of roots: αβ = c / a
  • Difference of roots: |α - β| = √D / |a|
  • Forming equation from roots: x2 - (α + β)x + αβ = 0

4. Common Algebraic Identities for Exam Questions

α² + β² = (α + β)² - 2αβ
α³ + β³ = (α + β)³ - 3αβ(α + β)
1/α + 1/β = (α + β) / αβ = -b / c

Important Exam Facts

  • If one root is p + √q (irrational), the other root is automatically its conjugate p - √q (when coefficients are rational).
  • If a + b + c = 0, then x = 1 and x = c / a are always the two roots.
  • Maximum or minimum value of ax2 + bx + c occurs at x = -b / 2a and equals (4ac - b2) / 4a.
