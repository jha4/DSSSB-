Linear Equations in One and Two Variables

Definition: A linear equation is an algebraic equation in which the highest power of every variable is 1. Its graph in the Cartesian plane is always a straight line.

1. Standard Forms

  • One variable: ax + b = 0 (where a ≠ 0) → unique solution x = -b / a.
  • Two variables: ax + by + c = 0 (where a, b are not both zero).

2. Pair of Linear Equations: Consistency Conditions

Consider two linear equations: a1x + b1y + c1 = 0 and a2x + b2y + c2 = 0.

Ratio Condition Graphical Representation Algebraic Solution System Type
a1/a2 ≠ b1/b2 Intersecting lines Exactly one (unique) solution Consistent
a1/a2 = b1/b2 = c1/c2 Coincident lines Infinitely many solutions Consistent (Dependent)
a1/a2 = b1/b2 ≠ c1/c2 Parallel lines No solution Inconsistent

3. Methods of Solving

  1. Substitution Method: Express one variable in terms of the other from one equation and substitute into the second.
  2. Elimination Method: Equalize coefficients of one variable and add or subtract the equations.
  3. Cross-Multiplication Formula:
x / (b1c2 - b2c1) = y / (c1a2 - c2a1) = 1 / (a1b2 - a2b1)

Important Exam Facts

  • If a system has no solution, the lines are strictly parallel (a1/a2 = b1/b2 ≠ c1/c2).
  • For homogeneous equations (c1 = c2 = 0), (0, 0) is always a trivial solution; non-zero solutions exist only when a1b2 = a2b1.
  • Questions asking to find k for "unique solution" or "infinite solutions" directly test the coefficient ratio table above.
