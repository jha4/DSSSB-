.NET, ASP.NET and Server-side Development

.NET platform and runtime

.NET is a developer platform containing runtimes, libraries, tools and language support. The modern .NET platform is cross-platform; the older .NET Framework is primarily Windows-focused.

  • CLR (Common Language Runtime) is the managed execution environment. It provides garbage collection, exception handling, type safety and runtime services.
  • MSIL/CIL (Microsoft/Common Intermediate Language) is CPU-independent intermediate code produced by .NET language compilers.
  • JIT (Just-In-Time) compiler translates intermediate code into native machine instructions at runtime; JIT is part of the CLR execution process.
  • FCL/BCL: framework/base class libraries providing reusable types and APIs.
  • CTS: Common Type System defines how types are declared/used in the runtime; CLS: Common Language Specification defines rules for language interoperability.

ASP.NET and web controls

ASP.NET is Microsoft's server-side web development framework. Classic Web Forms server controls are processed on the server and use runat="server". Example:

<asp:TextBox ID="txtName" runat="server" />
  • Server control: a control represented and processed on the server; it can participate in page lifecycle and render HTML to the browser.
  • Data binding: connects data from a source to controls so the UI can display (and sometimes edit) data.
  • Application state: shared application-wide storage accessible across pages/users within the application.
  • Session state: per-user/session data.
  • ViewState: Web Forms mechanism that preserves page/control values across postbacks.
  • System.Web.UI: namespace associated with ASP.NET Web Forms page/control infrastructure in .NET Framework.
  • AJAX in ASP.NET: asynchronous partial-page updates; classic ASP.NET AJAX included UpdatePanel.

MVC and web services

MVC separates concerns: Model represents data and business rules; View presents output; Controller handles input and coordinates model/view actions. In AngularJS, ng-model binds model data to a view; do not confuse this with ASP.NET MVC's server-side architecture.

Web service/API: an interface through which applications exchange data. REST APIs commonly use HTTP methods and resource-oriented URLs; SOAP is a protocol/message framework commonly using XML.

Related .NET terminology

  • ADO.NET: .NET data-access technology for working with data sources; includes connected objects such as Connection/Command/DataReader and disconnected DataSet/DataAdapter patterns.
  • WPF: Windows Presentation Foundation, a UI framework for Windows desktop applications; it is not a web protocol.
  • VB.NET and C# are .NET languages. Java is not a .NET language in the usual platform classification.
  • A constructor in C# has the same name as its class and has no return type. If no constructor is declared, a default parameterless constructor is generally supplied for a class.

Applets and legacy technology

Java applets were historically embedded in web pages but are obsolete in modern browsers and should be studied only as a historical syllabus term. ActiveX controls are also legacy Windows/Internet Explorer-era technology; do not treat them as modern cross-browser web components.

High-yield: CLR, JIT, MSIL/CIL, server controls and runat="server", data binding, Application vs Session state, ADO.NET, MVC and legacy applet/ActiveX terminology.

  1. PYQ #5 · 2023 · DSSSB TGT Computer Science

    ________ is the standard that defines how web servers and application programs communicate.

    1. A. JDBC
    2. B. ODBC
    3. C. CGI
    4. D. HTTP

    Correct answer: D. HTTP

    Explanation (workbook): Core Concept: HTTP (Hypertext Transfer Protocol) is the foundational protocol for data communication on the World Wide Web. It defines how messages are formatted and transmitted, and what actions web servers and browsers should take in response to various commands. This includes how web servers communicate with application programs (e.g., through APIs or server-side scripting) to serve dynamic content.

    Why other options are incorrect: JDBC (Java Database Connectivity) and ODBC (Open Database Connectivity) are APIs for connecting to and querying databases, not for general web server-application communication. CGI (Common Gateway Interface) is an older standard for web servers to interface with external applications, but HTTP is the underlying protocol that defines the communication itself.

  3. PYQ #14 · 2023 · DSSSB TGT Computer Science

    _____ is a code that consists of CPU and platform-independent set of instructions, which can be easily converted to the native code.

    1. A. DLL
    2. B. FCL
    3. C. JIT
    4. D. MSIL

    Correct answer: D. MSIL

    Explanation (workbook): Core Concept: MSIL (Microsoft Intermediate Language), now commonly referred to as CIL (Common Intermediate Language), is a CPU and platform-independent set of instructions. Source code written in .NET languages (like C# or VB.NET) is compiled into MSIL, which is then converted to native machine code at runtime by a Just-In-Time (JIT) compiler.

    Why other options are incorrect: DLL (Dynamic Link Library) is a file format for libraries. FCL (Framework Class Library) is a collection of reusable classes. JIT (Just-In-Time) is the compiler that translates MSIL, not the intermediate code itself.

  4. PYQ #23 · 2023 · DSSSB TGT Computer Science

    Which of the following is the execution engine for .NET applications and servers as the interface between .NET applications and the operating system?

    1. A. Framework Class Library (FCL)
    2. B. Common Type System (CTS)
    3. C. Common Language Specifications (CLS)
    4. D. Common Language Runtime (CLR)

    Correct answer: D. Common Language Runtime (CLR)

    Explanation (workbook): Core Concept: The Common Language Runtime (CLR) is the virtual machine component of Microsoft's .NET framework. It is the execution engine that manages the execution of .NET programs. It provides services such as memory management (garbage collection), exception handling, type safety, and security, acting as the interface between .NET applications and the underlying operating system.

    Why other options are incorrect: 'Framework Class Library (FCL)' is a comprehensive collection of reusable classes, interfaces, and value types, but it's a library, not the execution engine. 'Common Type System (CTS)' defines how types are declared, used, and managed in the CLR, but it's a specification, not the execution engine. 'Common Language Specifications (CLS)' is a set of rules that define a subset of the CTS, ensuring language interoperability, but it's also a specification, not the execution engine.

    1. A. Machine language
    2. B. Intermediate language
    3. C. Assembly language
    4. D. High level language

    Correct answer: B. Intermediate language

    Explanation (workbook): Core Concept: .NET Framework programs are compiled into an Intermediate Language (IL), also known as Common Intermediate Language (CIL) or Microsoft Intermediate Language (MSIL).
