1. Artificial Intelligence fundamentals

Artificial Intelligence (AI) is the study and engineering of systems that perform tasks associated with intelligent behaviour, such as perception, reasoning, learning, planning and language processing.

  • Search problem: defines an initial state, actions, transition model, goal test and path cost. Breadth-first search explores by depth; depth-first search explores along a branch; uniform-cost search expands the lowest-cost frontier node.
  • Heuristic: estimate of remaining cost to a goal. A* evaluates f(n)=g(n)+h(n), where g is cost so far and h is estimated remaining cost. An admissible heuristic does not overestimate the true remaining cost.
  • Machine learning: systems learn patterns from data. Supervised learning uses labelled examples; unsupervised learning finds structure without target labels; reinforcement learning learns from rewards and penalties.
  • Expert system: rule-based system using a knowledge base and inference engine; see MIS/DSS notes for its architecture.
