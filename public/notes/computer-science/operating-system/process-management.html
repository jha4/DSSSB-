Process Management & CPU Scheduling Algorithms

Definition: A process is a program in execution, represented inside the OS by a Process Control Block (PCB) storing its PID, state, program counter, registers, and memory limits.

1. Five-State Process Lifecycle

  1. New: Process is being created by the OS.
  2. Ready: Loaded in main memory, waiting in the ready queue for CPU allocation.
  3. Running: Instructions are actively executing on a CPU core.
  4. Waiting (Blocked): Waiting for an I/O completion or event signal.
  5. Terminated: Execution completed and PCB is deallocated.

2. Comparison of CPU Scheduling Algorithms

Algorithm Preemptive? Starvation Risk Key Exam Characteristic
FCFS No No Suffers from Convoy Effect
SJF / SRTF SJF: No / SRTF: Yes Yes (long jobs) Minimum average waiting time
Round Robin (RR) Yes (Time Quantum) No Best for time-sharing interactive systems
Priority Scheduling Optional Yes (Fixed via Aging) High-priority tasks execute first

3. Scheduling Formulas

Turnaround Time (TAT) = Completion Time - Arrival Time
Waiting Time (WT)     = Turnaround Time - Burst Time
Response Time (RT)    = First CPU Time - Arrival Time

Important Exam Facts

  • Aging prevents starvation in Priority Scheduling by gradually increasing the priority of waiting processes.
  • When Time Quantum q → ∞ in Round Robin, it behaves identically to FCFS.
  • A Medium-Term Scheduler handles swapping processes between main memory and disk to control degree of multiprogramming.
