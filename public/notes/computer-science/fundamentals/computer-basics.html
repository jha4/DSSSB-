Computer Fundamentals: Architecture, Memory & Number Systems

Von Neumann Architecture: Proposed by John von Neumann (1945), where both program instructions and data share the same memory space and bus system.

1. Core Functional Units of a Computer

  • Input Unit: Converts human-readable input into binary form (Keyboard, Mouse, Scanner, MICR, OCR).
  • CPU (Central Processing Unit):
    • ALU (Arithmetic Logic Unit): Performs arithmetic (+, -, *, /) and logical comparisons (>, <, =).
    • CU (Control Unit): Directs instruction fetch-decode-execute cycle and timing signals.
    • Registers: Fastest memory inside CPU (PC, IR, MAR, MDR, Accumulator).
  • Memory Unit & Output Unit: Stores instructions/results and delivers processed output.

2. Memory Hierarchy (Fastest to Slowest)

Memory Level Volatility Speed & Cost per Bit Primary Technology / Role
CPU Registers Volatile Fastest / Highest Immediate operands & instruction pointers
Cache Memory (L1/L2/L3) Volatile Very Fast SRAM (Static RAM) bridging CPU and RAM
Main Memory (RAM) Volatile Fast DRAM (needs periodic refreshing)
ROM / BIOS / EEPROM Non-Volatile Moderate Bootloader / Firmware storage
Secondary Storage (SSD/HDD) Non-Volatile Slowest / Lowest cost Long-term OS & user files

3. Memory Units & Binary Conversion

1 Bit   = 0 or 1
1 Nibble = 4 Bits
1 Byte   = 8 Bits
1 KB     = 1024 Bytes (2¹⁰)
1 MB     = 1024 KB    (2²⁰ Bytes)
1 GB     = 1024 MB    (2³⁰ Bytes)
1 TB     = 1024 GB    (2⁴⁰ Bytes)

Important Exam Facts

  • SRAM uses flip-flops (faster, used in Cache); DRAM uses capacitors (slower, needs refreshing, used in main RAM).
  • EEPROM (Electrically Erasable Programmable ROM) is the basis of modern flash drives and BIOS updates.
  • POST (Power-On Self-Test) runs from ROM/BIOS immediately when a computer is powered on.
