JavaScript, DOM, DHTML and AJAX

JavaScript fundamentals

JavaScript is a programming language used to add behaviour to web pages and also used in server runtimes. A JavaScript source file commonly uses the .js extension.

  • Embed code with <script> ... </script>; load an external file with <script src="app.js" defer></script>.
  • let and const are block-scoped; var is function-scoped. A const binding cannot be reassigned, though an object it references may be mutated.
  • Use === for strict equality when implicit type conversion is not intended.
  • Functions are reusable callable blocks. A callback is a function passed to another function to be called later, for example after an event or asynchronous operation.
  • Arrays are zero-indexed. Common methods include push, pop, slice, splice, map, filter and forEach.
  • for...in iterates enumerable property keys; for...of iterates values from an iterable.

Browser objects and the DOM

  • DOM (Document Object Model) represents a document as a tree of objects/nodes that scripts can inspect and modify.
  • window: top-level browser window/global object; document: current page document; location: current URL/navigation; history: session history; navigator: browser/device information.
  • Useful methods: getElementById(), querySelector(), querySelectorAll(), createElement(), append(), remove(), addEventListener().
  • document holds the document content/tree; window is the containing browser window.
  • Dialogs: alert() displays a message; confirm() asks for confirmation; prompt() requests text input.

Events and event handling

Register handlers with addEventListener(). An event object provides information about the event. Call event.preventDefault() to stop the browser's default action, such as a normal form submission. Use stopPropagation() to stop further propagation through the event path.

Forms, validation and asynchronous requests

  • form.submit() submits a form programmatically but bypasses constraint validation and does not dispatch the normal submit event. form.requestSubmit() behaves more like activating a submit button.
  • Client-side validation gives immediate feedback but must be repeated on the server because browser code can be bypassed.
  • Regular expressions test patterns; a successful regex does not prove an email address exists or is deliverable.
  • Promises represent eventual success/failure. async/await is syntax for working with promises.
  • AJAX (Asynchronous JavaScript and XML) is a technique for making asynchronous requests and updating part of a page without a full reload. Modern apps often exchange JSON rather than XML; AJAX is not a programming language.

DHTML and jQuery

DHTML means Dynamic HTML: a combination of HTML, CSS, JavaScript and the DOM used to change page content or style dynamically. It is not a separate markup language. jQuery is a JavaScript library; animation methods include slideDown(). The DOM style API can change CSS properties, while window.resizeTo() is a legacy/browser-restricted method for resizing a window.

High-yield: .js extension, script tag, callback, DOM vs window/document, event names, preventDefault(), prompt(), for...in, AJAX and DHTML.
