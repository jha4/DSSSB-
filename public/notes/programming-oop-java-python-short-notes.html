1. Programming fundamentals and problem-solving

A program is a set of instructions written in a programming language to perform a task. Programming translates a problem-solving method into executable instructions. A variable is a named reference/storage location whose value may change; a constant represents a value intended not to change.

Language levels

LanguageMeaningTranslator
Machine languageBinary instructions executed directly by CPU; hardware dependentNo separate translator
Assembly languageMnemonic representation of machine instructionsAssembler
High-level languageMore human-readable, generally portable source notationCompiler and/or interpreter/runtime

Compiler: translates source code into target code (often object code or bytecode). Interpreter: executes a program through an interpretation process. Real language implementations can combine compilation, bytecode and interpretation; these are introductory distinctions, not universal implementation rules.

Core terms

  • Syntax: grammatical rules of a language. A syntax error violates those rules.
  • Semantics: meaning/behaviour of valid constructs.
  • Identifier: name for a variable, function, class or other program entity; permitted characters and starting rules depend on language.
  • Keyword: reserved word with a predefined language meaning.
  • Data type: defines a set of values and operations, and often storage representation.
  • Debugging: locating, understanding and correcting defects.
  • Modular programming: decomposes a program into smaller modules with clear responsibilities.

Control structures

StructurePurposeExamples
SequenceExecute statements in orderAssignment followed by output
SelectionChoose a branchif/else, switch
IterationRepeat a blockfor, while, do-while

break exits the nearest loop or switch. continue skips the remainder of the current loop iteration. A function is a reusable unit of code; a parameter appears in its definition and an argument is supplied at the call.

2. C programming — language fundamentals

C is a general-purpose procedural language. A typical hosted C program defines main as its entry point and includes declarations for library facilities it uses, such as stdio.h for standard input/output.

Basic program structure

#include <stdio.h>
int main(void) {
    int value = 10;
    printf("%d\\n", value);
    return 0;
}
  • #include is a preprocessor directive that makes declarations from a header available.
  • main is the program entry function in a hosted C environment; int main(void) is a standard form.
  • printf formats output; scanf reads formatted input. For most scanf conversions, pass the address of the destination variable.
  • Statements generally end with a semicolon. Braces delimit compound statements/blocks.

Fundamental data types

Exact type sizes and ranges are implementation-dependent within standard minimum requirements. Use sizeof; do not assume every machine uses the same byte width for every type.

Precedence determines grouping; associativity determines grouping when operators have equal precedence. Parentheses should be used when clarity matters. && and || short-circuit. In C, ^ is bitwise XOR, not exponentiation. The comma operator evaluates its left operand, discards that result and yields the right operand.

Critical trap: modifying the same scalar more than once between sequence points / without the sequencing required by the C standard can produce undefined behaviour. Do not assume a compiler-specific output for expressions such as multiple unsequenced increments of one variable.

Control statements and loops

  • if / else: conditional branch.
  • switch: selects a matching case label. Execution can fall through into subsequent cases unless terminated with break or another control transfer.
  • for: initialization; condition; update; body. Suitable for count-controlled repetition.
  • while: tests condition before executing the body; may execute zero times.
  • do-while: executes body before testing condition; executes at least once.
  • An infinite loop does not terminate under its current control conditions.

3. C arrays and strings

An array is a fixed-size sequence of elements of the same type stored contiguously. C array indexing begins at zero. For int a[5], valid indices are 0 through 4.

  • Array declaration: int marks[10];
  • Initialization: int a[3] = {10, 20, 30};
  • Two-dimensional array: int matrix[2][3];; in C, rows are stored contiguously (row-major order).
  • Out-of-bounds access is undefined behaviour.
  • In most expressions, an array expression converts to a pointer to its first element. The array object is not itself a modifiable pointer variable.

A C string is a character array terminated by the null character '\\0'. Its storage must include space for that terminator. Common functions from string.h include strlen, strcpy, strncpy, strcat, strcmp and strchr; ensure destination buffers are large enough.

4. C functions, scope and storage classes

A function has a declaration/prototype, definition and call. A function prototype tells the compiler the function's name, return type and parameter types. C uses pass by value: parameter values are copied. To modify a caller's object, pass its address using a pointer.

  • Recursion: a function calls itself; a base case prevents endless calls.
  • Scope: region in which an identifier is visible.
  • Lifetime: period during which an object's storage exists.
  • auto: ordinary block-scope automatic storage duration (default for many local objects).
  • register: historical hint for register storage; it does not guarantee a CPU register.
  • static: static storage duration; a block-scope static object retains its value between calls. At file scope it gives internal linkage.
  • extern: declares an object/function with external linkage in common use.

Variadic functions accept a variable number of arguments; declarations and macros for them are provided by stdarg.h, using va_list, va_start, va_arg and va_end.

5. C pointers and dynamic memory

A pointer stores the address of an object or function. The address-of operator & obtains an object's address; unary * dereferences a valid pointer to access the pointed-to object.

int value = 7;
int *p = &value;
*p = 12;   /* value is now 12 */
  • int *p declares a pointer to int.
  • int **q declares a pointer to a pointer to int.
  • Pointer arithmetic advances in units of the pointed-to type, not raw bytes.
  • Array indexing is defined in terms of pointer arithmetic: a[i] is equivalent to *(a + i).
  • A null pointer points to no object. Never dereference a null, dangling or otherwise invalid pointer.
  • A dangling pointer refers to an object whose lifetime has ended; use-after-free is unsafe.
FunctionPurposeInitialization
malloc(bytes)Allocate a block of bytesUninitialized contents
calloc(count,size)Allocate array-like blockAll bits set to zero

Check allocation results for NULL. Store realloc into a temporary pointer so the original allocation is not lost on failure. Every successful allocation should have a clear ownership/release path.

6. C structures, unions, enums and files

Structure groups multiple named members, potentially of different types; each member has its own storage (subject to padding/alignment). Union lets its members share the same storage area; it is generally large enough for its largest member plus alignment requirements. At a time, interpret the member whose value was most recently stored, subject to language rules.

  • struct: record with separate members.
  • union: overlapping member storage.
  • typedef: introduces a type alias.
  • enum: defines named integer constants.

File handling uses FILE * and functions such as fopen, fclose, fprintf, fscanf, fgets, fputs, fread and fwrite. Check whether fopen returned NULL. Common modes include r, w, a, and update variants r+, w+, a+; binary variants append b.

7. C++ programming essentials

C++ supports procedural, object-oriented and generic programming. It retains many C-like constructs and adds classes, references, overloading, templates, exceptions and the Standard Template Library.

  • Input: cin >> value; uses the stream extraction operator >>.
  • Output: cout << value; uses the stream insertion operator <<.
  • Namespace: named scope that helps organize identifiers and avoid naming conflicts; std contains standard-library names.
  • Scope resolution: :: qualifies a name in a namespace or class.
  • Reference: alias for an existing object; must be initialized and cannot be reseated.
  • new/delete: allocate/deallocate objects; prefer standard containers and smart pointers for safe ownership in modern C++.

Inline function: an inline declaration permits multiple definitions under the One Definition Rule and is a request/permission related to inlining; the compiler is not required to substitute the body at every call.

9. C++ inheritance, polymorphism and class features

  • Single: one base class.
  • Multiple: more than one direct base class.
  • Multilevel: inheritance chain.
  • Hierarchical: multiple derived classes share a base.
  • Hybrid: combination of inheritance forms.
  • Virtual function: enables runtime dispatch through base pointers/references.
  • Pure virtual function: declared with = 0; a class with an unimplemented pure virtual function is abstract.
  • Friend function: non-member function granted access to private/protected class members.
  • Copy constructor: initializes an object from another object of the same class.
  • Templates: support generic functions/classes parameterized by types or values.

Common STL containers: vector (dynamic array), list (doubly linked list), deque, stack, queue, priority_queue, set, map and their unordered variants. This is enrichment beyond the narrow C++ wording in the supplied syllabus, but useful for broader preparation.

10. Java fundamentals and runtime architecture

Java source code is compiled by javac into platform-neutral bytecode stored in class files. A JVM loads and executes bytecode, interpreting it and/or compiling hot code with a Just-In-Time (JIT) compiler.

TermMeaning
JDKJava Development Kit: compiler and development tools plus runtime components
JREJava Runtime Environment: JVM and libraries needed to run Java applications (traditional packaging term)
JVMAbstract virtual machine specification and implementation that executes bytecode
BytecodeIntermediate instruction set stored in .class files
javacJava compiler
javapClass-file disassembler / class-file inspection tool

Java is statically typed and class-based. A typical method has a return type, method name, parameter list and body. Statements normally end in semicolons; methods are declared inside classes/interfaces. The JVM provides class loading, verification, runtime memory management and execution.

Java data types and operators

Eight primitive types: byte, short, int, long, float, double, char and boolean. Reference types include classes, arrays, interfaces and enums. Java integer literals can use decimal, hexadecimal (0x), binary (0b) and octal (leading 0) forms.

11. Java OOP, access control and exceptions

  • Class/object: class defines members; object is an instance.
  • Inheritance: a class can extend one class; Java supports implementing multiple interfaces.
  • Interface: reference type defining a contract; can include abstract, default, static and private methods under modern Java rules.
  • Abstract class: cannot be instantiated directly; can contain abstract and concrete methods.
  • Overloading: same method name with different parameter lists. Overriding: subclass redefines inherited instance method subject to access/return/exception rules.
  • final class: cannot be subclassed. final method: cannot be overridden. final variable: assigned once (for a blank final, exactly once under definite-assignment rules).
ModifierAccess summary
publicAccessible wherever the containing type/member is accessible
protectedSame package and qualifying subclass access
package-private (no modifier)Same package
privateWithin declaring top-level class/nest access rules

Exception handling: try encloses risky code; catch handles matching exceptions; finally is used for cleanup and normally executes after try/catch completion. throw throws an exception object; throws declares possible exceptions in a method signature.

  • Checked exceptions: compiler requires handling or declaration (except unchecked exception classes).
  • Unchecked exceptions: subclasses of RuntimeException and Error; no mandatory catch/declare requirement.
  • Custom exception: define a class extending Exception or RuntimeException according to intended checked/unchecked behaviour.

12. Python fundamentals

Python is a high-level, dynamically typed language. Names refer to objects; indentation defines code blocks. A statement need not end with a semicolon. Comments begin with #.

Built-in data types

dictMutable key-value mapping; keys hashable{"a": 1}
setUnordered collection of unique hashable elements{1, 2, 3}

Operators and control flow

  • Arithmetic: + - * / // % **; // is floor division; ** is exponentiation.
  • Comparison: == != < <= > >=. Identity: is/is not. Membership: in/not in.
  • if/elif/else selects a branch; for iterates over an iterable; while repeats while a condition is true.
  • break exits a loop; continue skips to the next iteration; pass is a no-operation placeholder.
  • range(start, stop, step) generates an integer sequence-like iterable; stop is excluded.

Strings, lists, tuples and dictionaries

  • String indexing begins at 0; negative indices count from the end. Slice s[start:stop:step] excludes stop. Strings are immutable.
  • List is mutable. append(x) adds one item; extend(iterable) adds each item from an iterable.
  • Tuple is immutable as a sequence; a tuple may contain mutable objects, whose contents can still change.
  • Dictionary keys must be hashable; values may be mutable or immutable. keys(), values(), items() and get() are common methods.
  • == tests value equality; is tests object identity. Do not use identity to compare ordinary string or numeric values.

Functions and files

Define a function with def name(parameters):. Functions may return values with return. Python supports positional, keyword, default and variable-length arguments. File access commonly uses open(path, mode) and a context manager (with open(...) as f) so the file closes automatically.

13. Common code-tracing traps

  • Check operator precedence and associativity; add parentheses when uncertain.
  • Distinguish prefix increment from postfix increment, but do not rely on undefined/unsequenced C expressions.
  • In C, array indexing is pointer arithmetic; bounds are not automatically checked.
  • In C, switch execution may fall through without break.
  • In Java, + performs string concatenation when a string operand is involved; evaluation proceeds left to right.
  • In Python, // floors (including for negative values), and slices exclude the stop index.
  • In Python, lists are mutable while tuples and strings are immutable; dictionary keys must be hashable.
