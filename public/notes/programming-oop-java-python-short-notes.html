Programming, OOP, C/C++, Java and Python — Complete Notes

Coverage: Programming logic, control flow, functions, arrays, pointers, C/C++, object-oriented programming, Java runtime and Python data types.

1. Programming foundations

A program is an executable set of instructions. A programming language provides syntax and semantics for expressing algorithms. A variable names a storage location or value; a data type determines the kind of values and operations allowed.

  • Sequence: statements execute in order. Selection: if/else or switch chooses a branch. Iteration: loops repeat while a condition or count requires it.
  • Function: named reusable unit that may accept parameters and return a value. Scope determines where a name is visible.
  • Parameter: variable in a function definition. Argument: value supplied at a call.

2. C and C++ essentials

  • Fundamental C types: char, integer types, floating types and void. Exact widths depend on implementation; use sizeof rather than assuming identical widths.
  • Operators: arithmetic, relational, logical, bitwise, assignment, conditional and pointer operators. Precedence determines grouping; parentheses improve clarity.
  • Array: contiguous elements of the same type. In most expressions, an array name converts to a pointer to its first element; an array is not itself a modifiable pointer variable.
  • Pointer: stores an address. Dereferencing accesses the pointed-to object. Pointer arithmetic is scaled by the pointed-to type and must remain within the same array object (or one past its end).
  • String in C: character array terminated by null character '\0'. C++ provides std::string as a higher-level string type.
  • Structure: groups fields that may have different types. A union shares storage among its members.

3. Memory and function concepts

  • Call by value: function receives a copy of the argument value. In C, pointers can be passed so a function can modify an object through its address.
  • Recursion: function calls itself; each call has its own activation record and local state.
  • Dynamic allocation: C uses malloc/calloc/realloc/free; C++ commonly uses new/delete, containers and smart pointers.
  • Undefined behaviour: the language standard imposes no requirements; common causes include out-of-bounds access, use-after-free and signed integer overflow.

4. Object-oriented programming

Overloading resolves among methods/operators with different parameter signatures. Overriding replaces inherited behaviour in a subclass. A constructor initializes an object; it is not an ordinary method call.

5. Java

  • JDK: development kit including tools and runtime components. JRE: runtime environment. JVM: virtual machine that executes Java bytecode.
  • Java source is compiled into bytecode; the JVM interprets or JIT-compiles it for the host platform.
  • Java is class-based and object-oriented. For ordinary objects, == compares references; equals() can express logical equality when implemented.
  • Java supports single class inheritance but multiple interface implementation. Access modifiers include public, protected, package-private and private.

6. Python

  • List: ordered, mutable sequence. Tuple: ordered, immutable sequence. Dictionary: mutable key-value mapping. Set: collection of unique hashable elements.
  • Python is dynamically typed; names refer to objects. Indentation defines suites/blocks.
  • Strings are immutable. Slicing uses start:stop:step, where stop is excluded. range() commonly produces an iterable sequence of integers.
  • Functions use def; exceptions are handled with try/except/finally. A module groups reusable code.

7. Exam traps

  • In C, a[i] is equivalent to *(a+i). Pointer variable and pointed-to value are different.
  • Java bytecode runs on a JVM. List is mutable; tuple is immutable.
  • A Python dictionary is a mapping, not a positional array.

Program design, pseudocode and flowcharts

Program development typically proceeds through problem definition, input/output identification, algorithm design, dry run, coding, testing and refinement. Pseudocode expresses an algorithm in structured, language-independent statements; it is not governed by one universal syntax.

Use sequence for straight-line steps, selection for if/else decisions, and iteration for loops. A dry run traces variable values for a sample input and is useful for detecting logic errors before execution.
