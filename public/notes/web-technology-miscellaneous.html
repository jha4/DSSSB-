Miscellaneous Web Concepts

PHP and Apache

  • PHP: a server-side scripting language commonly used to generate dynamic web pages. Common comment forms are //, # for single-line comments and /* ... */ for block comments.
  • Apache HTTP Server: open-source web-server software. PHP and Apache are separate technologies: one is a server-side language, the other is server software.
  • CGI: Common Gateway Interface, a standard interface through which a web server can invoke external programs/scripts to generate dynamic responses.

Website visibility and user trust

Clear, memorable site names, useful original content, accessible navigation, search-friendly metadata and regular updates can improve discoverability. Do not mislead users or collect/share location and personal data without informed consent and appropriate controls.

ActiveX and older browser technologies

ActiveX was a Microsoft technology used mainly in older Windows/Internet Explorer environments. Tabular Data Control was an ActiveX control associated with displaying data in tabular form. These are historical technologies, not recommended modern web-development choices.

Quick supplementary revision

  • Web server software receives requests and returns static or dynamically generated responses; it does not itself provide every application/business service.
  • Browser privacy/location permissions should be explicit and limited to trusted sites that need the feature.
  • Colour models may appear in web-related questions: RGB is additive; CMY is subtractive.
Exam focus: PHP vs Apache, CGI, website visibility, ActiveX/Tabular Data Control and privacy permissions.

  1. PYQ #49 · 2021 · DSSSB TGT Computer Science

    Which of the following is/are the open-source software(s)? I. PHP II. Apache

    1. A. Only II
    2. B. Only I
    3. C. Both I and II
    4. D. Neither I nor II

    Correct answer: C. Both I and II

    Explanation (workbook): Core Concept: I. PHP: PHP is a widely used open-source scripting language, especially suited for web development. Its source code is freely available and can be modified.II. Apache: The Apache HTTP Server (commonly known as Apache) is free and open-source web server software. It is maintained by the Apache Software Foundation.Both PHP and Apache are prominent examples of open-source software.

    Why other options are incorrect: Options A, B, and D are incorrect because both PHP and Apache are well-known examples of open-source software. Excluding either one or stating that neither is open-source is false.

  2. PYQ #76 · 2025 · DSSSB TGT Computer Science

    Which of the following actions demonstrates good netiquette in an online forum?

    1. A. Sharing personal information without permission
    2. B. Using proper grammar and punctuation
    3. C. Posting irrelevant content repeatedly
    4. D. Responding to others' posts with insults

    Correct answer: B. Using proper grammar and punctuation

    Explanation (workbook): Core Concept: Good netiquette ensures respectful, readable collaboration. Maintaining clear grammar, structured layouts, and purposeful communication supports healthy forum dialogue.

    Why other options are incorrect: Leaking private data records, spamming discussion spaces with noise, or posting flame attacks violates netiquette standards.
