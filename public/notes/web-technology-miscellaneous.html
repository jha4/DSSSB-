Miscellaneous Web Concepts

PHP and Apache

  • PHP: a server-side scripting language commonly used to generate dynamic web pages. Common comment forms are //, # for single-line comments and /* ... */ for block comments.
  • Apache HTTP Server: open-source web-server software. PHP and Apache are separate technologies: one is a server-side language, the other is server software.
  • CGI: Common Gateway Interface, a standard interface through which a web server can invoke external programs/scripts to generate dynamic responses.

Website visibility and user trust

Clear, memorable site names, useful original content, accessible navigation, search-friendly metadata and regular updates can improve discoverability. Do not mislead users or collect/share location and personal data without informed consent and appropriate controls.

ActiveX and older browser technologies

ActiveX was a Microsoft technology used mainly in older Windows/Internet Explorer environments. Tabular Data Control was an ActiveX control associated with displaying data in tabular form. These are historical technologies, not recommended modern web-development choices.

Quick supplementary revision

  • Web server software receives requests and returns static or dynamically generated responses; it does not itself provide every application/business service.
  • Browser privacy/location permissions should be explicit and limited to trusted sites that need the feature.
  • Colour models may appear in web-related questions: RGB is additive; CMY is subtractive.
Exam focus: PHP vs Apache, CGI, website visibility, ActiveX/Tabular Data Control and privacy permissions.

  1. PYQ #5 · 2023 · DSSSB TGT Computer Science

    ________ is the standard that defines how web servers and application programs communicate.

    1. A. JDBC
    2. B. ODBC
    3. C. CGI
    4. D. HTTP

    Correct answer: D. HTTP

    Explanation (workbook): Core Concept: HTTP (Hypertext Transfer Protocol) is the foundational protocol for data communication on the World Wide Web. It defines how messages are formatted and transmitted, and what actions web servers and browsers should take in response to various commands. This includes how web servers communicate with application programs (e.g., through APIs or server-side scripting) to serve dynamic content.

    Why other options are incorrect: JDBC (Java Database Connectivity) and ODBC (Open Database Connectivity) are APIs for connecting to and querying databases, not for general web server-application communication. CGI (Common Gateway Interface) is an older standard for web servers to interface with external applications, but HTTP is the underlying protocol that defines the communication itself.
  2. PYQ #34 · 2023 · DSSSB TGT Computer Science

    Which of the following is a Microsoft ActiveX control that will sort through a data file, extrapolate the necessary information and produce that information in specified areas on the web page?

    1. A. Dialog Bars
    2. B. Tabular Data Control
    3. C. Control Bars
    4. D. Dialog Boxes

    Correct answer: B. Tabular Data Control

    Explanation (workbook): Core Concept: The Tabular Data Control (TDC) was a Microsoft ActiveX control designed to allow web pages to bind to and manipulate tabular data (e.g., from delimited text files). It could sort, filter, and display this information in specified areas on a web page.

    Why other options are incorrect: Dialog Bars, Control Bars, and Dialog Boxes are user interface elements or containers, typically used for displaying information or collecting input, but they are not specifically designed for the advanced data sorting, extrapolation, and display functionalities described for tabular data on web pages.
