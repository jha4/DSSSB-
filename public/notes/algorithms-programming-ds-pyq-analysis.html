Scope: The supplied syllabus headings and the uploaded Part B workbook. The official syllabus detail used here is the Design & Analysis of Algorithms unit and the Programming, Data Structures, OOP & Java/Python unit. C/C++ is included exactly where the syllabus names it.

1. Source and method

  • Workbook: one worksheet, part b, with 1,870 data rows and columns for Exam, Year, Shift, Subject, Topic, Question Text, Options A–D, Correct Answer and Explanation.
  • Selected all records carrying one of these source topic labels: Algorithms, Data Structures, Data structures & algorithms, Programming, C, C / C++ & programming basics, C++, Java, Python and OOP concepts.
  • Selected total: 442 records. This is a source-label selection, not a claim that all 442 are perfectly classified or all strictly in-syllabus. Cross-topic items remain identifiable by their original source topic label.
  • Question stems were normalized for case, punctuation and whitespace to identify exact textual repetitions. Similar concept variants were reviewed separately; these are not counted as exact duplicates.

4. Exact repetitions and source quality

  • Raw exact duplicates: 29 repeated-stem groups contain 60 rows in total, or 31 occurrences beyond the first row in each group.
  • Case-insensitive and whitespace-normalized comparison: 36 groups contain 74 rows (38 excess occurrences). This catches formatting-only differences while retaining punctuation.
  • Punctuation-stripped candidate comparison: 49 groups contain 103 rows (54 excess occurrences). This is a broader candidate set, not an exact-duplicate count: stripping punctuation can merge distinct stems, so these groups require manual review before being called repeats.
  • All 442 selected records have a non-empty Correct Answer field. The workbook uses both A–D and 1–4 answer-key formats.
  • 441 records have an Explanation field; one does not (the 2018 Algorithms/Bubble Sort record).
  • 362 records have all four populated option fields; 16 have two or three populated options; 64 have no option text in the workbook. The 64 optionless records still have an answer-key value, but the corresponding option wording cannot be displayed from this source.

Examples of repeated stems or near-identical records include Python comment-symbol questions, Bubble Sort worst-case complexity, Quick Sort worst-case complexity, Linked List classification, hashing collision-resolution questions, Binary Search conditions, Java string-concatenation output, Selection Sort pass tracing and Radix Sort pass tracing. Exact duplicate totals are not the same as the number of repeated concepts.

Important: Correct Answer values are option identifiers (A–D or 1–4) in the workbook. The notes render the source key and corresponding option text. The key is preserved as supplied; it is not silently replaced with a different answer. Where the workbook omits options or explanation, that absence is disclosed in the question card.

5. Repeated concept families

Algorithms

  • Sorting: Bubble, Selection, Insertion, Merge, Quick and Radix Sort; stability, passes, comparisons, best/worst cases and nearly sorted inputs.
  • Complexity: time and space complexity, asymptotic bounds, loop-count analysis, recurrence relations and growth-rate ordering.
  • Searching: Linear and Binary Search, sorted-input requirement, direct middle-element access and comparison counts.
  • Algorithm properties: definiteness, finiteness, effectiveness, input/output, language independence and algorithm efficiency.
  • Design methods: Divide and Conquer, Greedy, Dynamic Programming, randomized methods, recursion, optimization and computational thinking.

Data Structures

  • Arrays: indexing, insertion/deletion shifts, row-major storage, address calculation, multidimensional and sparse arrays.
  • Linked Lists: node representation, singly/doubly linked lists, traversal, insertion/deletion and comparison with arrays.
  • Stacks and Queues: LIFO/FIFO, operations, applications, expression conversion and queue-end rules.
  • Trees and Heaps: binary-tree properties, BST insertion/deletion, traversals, AVL balance factors/rotations and heap insertion.
  • Hashing and Graphs: division method, collisions, probing, graph traversal and shortest-path concepts.

Programming and OOP

  • C: control statements, loops, switch fall-through, operators and precedence, output tracing, arrays, pointers, storage classes, functions, strings and structures.
  • C++: declarations, streams, namespace, pointers, arrays and object-oriented features.
  • Java: bytecode/JVM, classes and methods, access control, final, exceptions and output tracing.
  • Python: comments, identifiers, strings, slicing, operators, lists, tuples, dictionaries, file modes, Pandas and NumPy basics.
  • OOP: encapsulation, abstraction, inheritance, polymorphism, access modifiers and class/object concepts.

6. Single-occurrence and low-frequency concepts worth revising

These are examples found once or only a small number of times in the selected question text. Their revision value comes from their connection to the named syllabus or from being distinct examinable concepts—not from a statistically established prediction.

  • Algorithms: Newton's backward-difference interpolation (one record under the Algorithms label); Dijkstra single-source complexity (one); randomized-algorithm properties (one); computational-thinking steps in a Sudoku problem (one); path-graph degree reasoning (one); a Huffman/LCS/Quick Sort/Simplex technique-matching question (one); subset-sum solution tracing (two similar source-labelled records).
  • Data Structures: articulation-point identification (two records, one with an image reference); sparse tridiagonal matrix indexing; jagged arrays; Catalan-number count of BSTs; complete-binary-tree node counts; AVL deletion/balance-factor tracing; and heap construction/insertion.
  • Programming: C variadic arguments and stdarg.h; C structure/union memory layout; C pointer-to-pointer tracing; Java ClassLoader/package and custom-exception concepts; Python file modes, Pandas concatenation and Series/DataFrame distinctions.

Some source questions are image-based or have noisy OCR. For these, learn the underlying concept and do not memorize a possibly incomplete stem or option string as if it were a clean textbook statement.

7. Syllabus-to-PYQ coverage

Explicitly named in the supplied syllabus and represented in the PYQs

  • Problem-solving, algorithms, pseudocode, flowcharts and programming logic.
  • Linear/Binary Search; Bubble, Selection, Insertion, Merge and Quick Sort basics.
  • Time/space complexity, Big-O, Big-Ω, Big-Θ and best/average/worst cases.
  • Recursion, Divide and Conquer, Greedy, Dynamic Programming and graph traversal.
  • Stacks, Queues, Linked Lists, Trees, BST and graph basics.
  • C/C++ data types, operators, expressions, input/output, strings, arrays, pointers, functions and structures.
  • OOP principles; Java bytecode/JVM/class/method syntax; Python data types, operators, strings, lists, tuples, dictionaries, loops, functions and tracing.

Explicitly named but less comprehensively represented

  • Top-down design and modular programming are present in the syllabus; prepare the full design workflow and decomposition methods.
  • Greedy and Dynamic Programming are named at an introductory level; learn the idea, conditions and canonical examples rather than assuming the PYQ count alone is sufficient.
  • Shortest path and Minimum Spanning Tree are explicitly named at basic level; learn BFS/DFS, Dijkstra, Prim and Kruskal at least conceptually.
  • Java class/method syntax and Python functions/basic tracing are explicit syllabus items; practise short code snippets even when a particular syntax point is not repeated often.

Additional enrichment — not an explicit promise of examination coverage

Advanced AVL operations, heaps, hashing, sparse-matrix storage, B-Trees/B+ Trees, tries, Disjoint Set Union, Bellman–Ford, Floyd–Warshall, topological sorting, advanced dynamic programming, C preprocessor details, C++ templates/STL, Java collections and multithreading, and Python generators/comprehensions are useful extensions. Prioritize them after the explicitly named syllabus and the recurring PYQ families.

8. Study priority inferred from this workbook

  1. Very high: C output tracing, operators/control flow, arrays/pointers/functions; sorting/searching/complexity; linked lists, arrays, trees and stacks/queues.
  2. High: Java/Python fundamentals and output tracing; hashing; BST/AVL/heap; recursion and design paradigms.
  3. Moderate but syllabus-required: graph traversal, shortest path/MST basics, top-down/modular design, structures/unions, OOP distinctions and file handling.
  4. Extension: advanced data structures and language features not expressly listed in the supplied syllabus.

These are preparation priorities, not calibrated probabilities. The workbook is a multi-year question collection; counts do not establish the probability of a topic appearing in the next examination.

9. Predicted practice questions — not actual PYQs

Algorithms

  • Compare the best, average and worst time complexities of common sorting algorithms.
  • Trace Binary Search and state why sorted data and direct middle access matter.
  • Determine the complexity of nested loops and simple recurrences.
  • Distinguish Greedy, Divide and Conquer and Dynamic Programming.
  • Identify BFS/DFS data structures and basic shortest-path/MST algorithms.

Data Structures

  • Trace stack/queue operations and infix/postfix evaluation.
  • Calculate array addresses in row-major order.
  • Trace BST traversals and deletion cases.
  • Identify AVL balance factors and the correct rotation.
  • Perform heap insertion and resolve a hash collision by linear probing.

Programming

  • Trace C operator precedence, short-circuit evaluation, loops and switch statements.
  • Predict pointer, array and string outputs while identifying undefined behaviour.
  • Differentiate structure and union, storage classes and dynamic allocation.
  • Distinguish OOP principles, overloading and overriding.
  • Trace Java bytecode/runtime concepts and Python collection/slicing/file operations.

10. Interpretation cautions

  • Source topic labels are not a perfect taxonomy. A few records under combined labels mention adjacent topics such as PHP, .NET, SQL, operating-system allocation or business terminology. They are retained under their original workbook category rather than silently reclassified.
  • Image-based questions may refer to figures not embedded in the text field. Their original text is retained, but a missing image cannot be reconstructed from the workbook row alone.
  • Predictions are model-based study guidance, not claims about the examiner's future paper.
