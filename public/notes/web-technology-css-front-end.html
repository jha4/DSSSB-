CSS, Layout and Front-end Tools

CSS syntax and inclusion methods

CSS means Cascading Style Sheets. It controls the presentation of HTML. A CSS rule contains a selector and declaration block; each declaration is a property–value pair.

p.notice { color: #234; font-weight: 700; }
<link rel="stylesheet" href="style.css">
  • Inline CSS: style attribute on an element.
  • Internal CSS: rules inside a <style> element.
  • External CSS: separate .css file linked with <link rel="stylesheet" href="...">; best for reuse and separation of concerns.

Selectors and cascade

  • Element: p; class: .card; ID: #header; universal: *; attribute: [type="text"].
  • Combinators: descendant (space), child (>), adjacent sibling (+), general sibling (~).
  • Pseudo-classes: :hover, :visited, :focus. Pseudo-elements: ::before, ::after.
  • Cascade resolution depends on origin/importance, specificity and source order. Inline styles normally outrank normal author rules; !important alters priority.

Colour models

CSS accepts named colours, hexadecimal, rgb(), rgba(), hsl() and hsla(). HSL means Hue (typically 0–360 degrees), Saturation and Lightness (percentages). RGB is additive; CMY is subtractive. For normalized RGB values, the simple complement conversion is C=1−R, M=1−G, Y=1−B.

Flexbox, Grid and responsive design

  • Flexbox: one-dimensional layout in a row or column; controls alignment and distribution along main and cross axes.
  • CSS Grid: two-dimensional layout system for rows and columns.
  • Responsive design: adapts layout to screen/viewport using fluid sizing, flexible media and media queries such as @media (max-width: 600px).
  • Box model: content + padding + border + margin. box-sizing: border-box includes padding and border in declared width/height.

Front-end tools, frameworks and preprocessors

  • Framework: provides reusable conventions/components/utilities. Bootstrap and Tailwind CSS are examples; Tailwind is utility-first.
  • Library: reusable code invoked by the application; React is commonly described as a JavaScript UI library.
  • Preprocessor: Sass/SCSS or Less extends CSS authoring with variables, nesting and related features, then compiles to CSS.
  • Font Awesome: icon library/asset collection. Reset CSS: normalises browser default styles. Chrome DevTools: browser inspection/debugging tools, not a CSS language.
  • Angular: front-end framework; jQuery: JavaScript library; PHP: server-side language, not a front-end design tool; SQL: database query language.
Exam traps: font-weight is boldness; list-style is shorthand; transition changes values smoothly; HSL is hue/saturation/lightness; Flexbox is one-dimensional and Grid is two-dimensional.

  4. PYQ #19 · 2023 · DSSSB TGT Computer Science

    How to change all images to black and white (100% grey)?

    1. A. img { filter: graycolor(100%);}
    2. B. img { filter: grayscale(100%);}
    3. C. img { graycolor(100%);}
    4. D. img { filter: "grayscale(100%)";}

    Correct answer: B. img { filter: grayscale(100%);}

    Explanation (workbook): Core Concept: In CSS, the `filter` property is used to apply visual effects to an element. The `grayscale()` function within the `filter` property converts the input image to grayscale. A value of `100%` means a complete conversion to black and white (100% grey), while `0%` would leave the image unchanged. Thus, `img { filter: grayscale(100%);}` is the correct syntax.

    Why other options are incorrect: `img { filter: graycolor(100%);}` is incorrect because `graycolor()` is not a valid CSS filter function. `img { graycolor(100%);}` is incorrect as it lacks the `filter:` property. `img { filter: "grayscale(100%)";}` is incorrect because the function value for `filter` should not be enclosed in quotes.
