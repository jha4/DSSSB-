1. Computer graphics fundamentals

  • Computer graphics: creation, storage, manipulation and display of visual information using computers.
  • Pixel: the smallest addressable picture element in a raster image or display. A pixel stores a colour/intensity value.
  • Resolution: number of pixels used to represent an image or display, commonly width × height (for example, 1920 × 1080). More pixels can represent finer detail, but resolution alone does not determine physical sharpness.
  • Aspect ratio: ratio of width to height. A 16:9 display is wider than a 4:3 display relative to its height.
  • Refresh rate: number of times a display refreshes per second, measured in hertz (Hz). A 60 Hz display refreshes 60 times per second.
  • Persistence: in classic CRT terminology, the time phosphor emission continues after the electron beam stops exciting it. Too little persistence can cause flicker; excessive persistence can cause smearing.
  • Raster graphics: represent images as pixels; enlargement may produce pixelation. Vector graphics: represent shapes mathematically using paths and geometric primitives; they scale cleanly before rasterization.

Display devices

CRT (Cathode Ray Tube): an electron gun produces a beam that is focused and deflected to strike phosphor on the screen. The phosphor emits light. A raster-scan CRT traces lines across the screen; a random-scan/vector display draws selected lines directly. Modern displays commonly use LCD/LED-backlit LCD or OLED technology rather than CRT.

3. 2D geometric transformations

Transformations change an object's position, size or orientation. Homogeneous coordinates allow translation, scaling and rotation to be represented using matrices. Matrix multiplication order matters because transformations are generally non-commutative.

  • Translation: moves every point by a displacement (tx, ty): x' = x + tx and y' = y + ty.
  • Scaling: changes size: x' = sx × x and y' = sy × y. Equal scale factors preserve proportions; unequal factors distort them.
  • Rotation: turns an object around an origin or pivot. In standard Cartesian coordinates, a positive angle is counter-clockwise.
  • Reflection: produces a mirror image across an axis or line.
  • Shearing: slants an object by shifting one coordinate in proportion to another.

To rotate about a point other than the origin, translate the pivot to the origin, rotate, then translate back. This order is important.

4. Viewing pipeline, clipping, curves and 3D modelling

Viewing pipeline: transforms object/model coordinates into world coordinates, then viewing/camera coordinates, projection coordinates and finally viewport/device coordinates. Clipping removes parts outside the viewing region before rasterization.

  • Clipping: discards portions of primitives outside a defined viewing window. Line-clipping algorithms include Cohen–Sutherland and Liang–Barsky. Polygon clipping is a related operation for polygon boundaries.
  • Curves: represent smooth paths or boundaries. Bezier curves are controlled by control points; B-splines use piecewise polynomial segments and provide local control.
  • Surface modelling: represents the exterior of 3D objects using surfaces, meshes or parametric patches.
  • Solid modelling: represents a complete 3D volume. Boundary Representation (B-rep) stores faces, edges and vertices; Constructive Solid Geometry (CSG) combines primitives using union, intersection and difference; voxel models divide space into volume cells.
  • Wireframe model: displays vertices and edges only. It does not explicitly represent filled surfaces or the object's interior.

Important distinction: clipping determines what lies inside the viewing region; a geometric transformation changes object coordinates. A curve is one-dimensional, a surface is two-dimensional, and a solid represents volume.

5. Multimedia fundamentals: image, audio and video

Multimedia combines two or more media types such as text, graphics, images, audio, video and animation in a computer-controlled presentation or application.

  • Sampling: converts a continuous-time signal into discrete-time samples by measuring it at regular intervals. Sampling frequency is measured in samples per second (Hz).
  • Nyquist sampling principle: for ideal reconstruction of a band-limited signal, sampling frequency must be greater than twice the highest signal frequency. Practical systems also use anti-aliasing filters.
  • Quantization: maps each sampled amplitude to one of a finite number of levels. With b bits per sample, there are 2^b possible quantization levels.
  • Bit depth: number of bits used for each sample or pixel component; greater bit depth permits more representable levels/colours.
  • Frame rate: number of video frames displayed per second (fps). Bit rate is the amount of encoded data per second.
  • Lossless compression: permits exact reconstruction of original data. Lossy compression: discards some information to obtain higher compression, often acceptable for image/audio/video.

6. Mobile computing: definition and architecture

Mobile computing is the use of portable computing devices and wireless communication to access data, applications and services while users or devices move between locations. It combines mobile hardware, wireless networks, mobile software and applications.

Three basic dimensions: mobile communication (wireless exchange), mobile hardware (portable devices and radio interfaces) and mobile software (operating systems, middleware and applications).

Layer / componentRole
Mobile device / User Equipment (UE)Phone, tablet or other terminal containing radio hardware, processor, memory, operating system and applications.
Radio access networkConnects the device over radio to the operator network; in GSM this includes BTS and BSC.
Core networkHandles switching/routing, subscriber services, mobility, authentication and connection to other networks.
Application/service layerProvides messaging, browsing, voice/video, location-based and enterprise services.

Wireless links may use cellular radio, Wi-Fi, Bluetooth, satellite or other radio technologies. A mobile device can change its point of attachment while sessions and services are maintained through mobility-management mechanisms.

7. GSM architecture and subscriber registers

GSM (Global System for Mobile Communications) is a widely deployed digital cellular standard associated with 2G. It uses SIM-based subscriber identity and a cellular network architecture.

  • MS / Mobile Station: the mobile equipment and SIM used by the subscriber.
  • BTS (Base Transceiver Station): radio equipment that communicates with mobile stations in a cell.
  • BSC (Base Station Controller): controls multiple BTSs and radio resources such as channel allocation and handover within its area.
  • MSC (Mobile Switching Centre): performs call switching and mobility-related control for a service area.
  • HLR (Home Location Register): central subscriber database containing permanent subscription/service information and current location-related routing information.
  • VLR (Visitor Location Register): temporary database for subscribers currently in an MSC area; it reduces repeated queries to the HLR.
  • AuC (Authentication Centre): supports subscriber authentication and security data.
  • EIR (Equipment Identity Register): stores equipment identity status information, such as permitted or barred device identities.
  • GMSC (Gateway MSC): gateway for routing calls between the mobile network and external telephone networks.

BTS vs BSC: BTS provides the radio link to devices; BSC manages a group of BTSs. HLR vs VLR: HLR stores home subscriber information; VLR stores temporary visitor-area information. VLR and the network cooperate to update the HLR when a subscriber's location area changes.

8. Mobile IP, Home Agent, Foreign Agent and Care-of Address

Mobile IP allows a mobile node to move between networks while remaining reachable through a stable home address. It separates the device's permanent home identity from its current point of attachment.

  • Mobile Node (MN): device that changes its point of attachment between networks.
  • Home Network: network associated with the mobile node's permanent home address.
  • Home Agent (HA): router on the home network that maintains the mobile node's current care-of information and forwards/tunnels packets toward the current location.
  • Foreign Agent (FA): in Mobile IPv4, a router in the visited network that can assist a visiting mobile node with registration and packet delivery.
  • Care-of Address (CoA): address representing the mobile node's current point of attachment or tunnel endpoint. It may be associated with a Foreign Agent or be a co-located address obtained by the mobile node.
  • Tunnelling: encapsulates packets so that they can be delivered from the home network toward the current care-of address.

Basic flow: the mobile node discovers a visited network, obtains or learns a CoA, registers the CoA with its Home Agent, and receives forwarded packets through a tunnel. The exact process differs between Mobile IPv4 and Mobile IPv6; Mobile IPv6 does not require a Foreign Agent in the same way as Mobile IPv4.

Memory cue: HA = home-network anchor; FA = router in the foreign/visited network (Mobile IPv4); CoA = current reachable endpoint/tunnel destination.

9. Mobility management and handover

Handover (handoff) is the transfer of an ongoing call or data session from one radio channel, cell, base station or network to another as the user moves or radio conditions change.

  • Intra-cell handover: channel/resource changes within the same cell.
  • Inter-cell handover: connection moves between cells; it may remain under the same controller or cross controller boundaries.
  • Inter-system handover: transfer between different radio access systems or network technologies, for example between satellite and terrestrial cellular systems.
  • Hard handover: break-before-make; old connection is released before the new one is fully established. Commonly associated with GSM-style handover.
  • Soft handover: make-before-break; device may maintain links with more than one base station temporarily. Associated with CDMA systems.
  • Macro-mobility: movement between larger network domains or administrative areas.
  • Micro-mobility: movement within a local domain, managed to reduce frequent global registration.
  • Ad hoc mobility: movement in a mobile ad hoc network (MANET), where topology changes as nodes move and links appear/disappear.

Mobility management includes location management (finding where a device is) and handover management (maintaining service while changing attachment points).

Relative data-speed ordering in common exam questions: GSM < GPRS < EDGE < LTE. This is a relative technology progression, not a guarantee of a particular real-world speed; actual throughput depends on spectrum, network configuration, device capability, signal quality and load.

CDMA is a multiple-access technique and also appears in cellular system families. Do not confuse the access technique itself with a single fixed generation label: IS-95 is associated with 2G, while CDMA2000 evolved into 3G.

12. Mobile operating systems, apps and mobile agents

Mobile operating system manages a portable device's processor, memory, files, processes, display, sensors, power, radio interfaces, permissions and application lifecycle.

  • Android: mobile operating system based on the Linux kernel, with an application framework and runtime environment.
  • iOS: Apple's mobile operating system for iPhone devices.
  • Other examples that may appear in older questions include Symbian, Windows Phone/Windows Mobile and BlackBerry OS. Their market status has changed; identify them as historical/mobile OS examples rather than current leading platforms.
  • Native app: built for a specific operating system/platform and can use platform APIs directly.
  • Mobile web app: runs through a browser and is delivered using web technologies.
  • Hybrid app: combines web technologies with a native wrapper/runtime.

Mobile agent: a software agent capable of moving between execution environments or hosts to perform tasks. A mobile agent may follow a predefined route or choose its route dynamically; this differs from a stationary agent that remains on one host.

13. Limitations, IoT challenges and haptic technology

  • Limited battery: radio communication, screen use and processing consume energy; power management is essential.
  • Bandwidth and coverage: wireless capacity varies with location, interference, spectrum and network congestion.
  • Variable connectivity: mobility can cause disconnections, latency changes and handover interruptions.
  • Security and privacy: devices may be lost or stolen and communicate over shared radio channels; authentication, encryption, secure updates and permissions matter.
  • Device constraints: small screens, limited input methods, thermal limits and varying hardware/software capabilities.
  • Transmission interference: radio signals can be affected by obstacles, fading, competing transmissions and environmental noise.
  • IoT adoption challenges: interoperability, security, privacy, power, connectivity, scalability, standards and device lifecycle management.
  • Haptic technology: provides tactile feedback to users through vibration, force feedback or other touch sensations. A phone vibration alert is a simple haptic output.

15. Rasterization and Line/Circle Drawing Concepts

Rasterization (scan conversion) converts geometric primitives such as lines, circles and polygons into a set of discrete pixels on a raster display. A line ideal in mathematics is continuous; the display must choose a finite sequence of pixels that best approximates it.

  • DDA (Digital Differential Analyzer): calculates incremental x/y changes using the line slope and rounds coordinates to the nearest pixel. It is simple but uses floating-point operations and rounding.
  • Bresenham line algorithm: uses an integer decision parameter to choose the next pixel. It is efficient because it avoids repeated floating-point calculations.
  • Midpoint circle algorithm: uses a decision function to select pixels near the ideal circle and exploits eight-way symmetry to calculate one octant and reflect the points.
  • Anti-aliasing: reduces jagged edges by smoothing pixel coverage/intensity; it does not change the underlying geometric object.

Do not mix the tasks: DDA and Bresenham are line rasterization methods; Cohen–Sutherland and Liang–Barsky are line clipping methods.

16. Projection and 3D Viewing Basics

  • Parallel projection: projection rays remain parallel. It preserves relative parallelism and is useful in engineering drawings. Orthographic projection uses projection directions perpendicular to the view plane; oblique projection uses an angled direction.
  • Perspective projection: projection rays converge at a centre of projection. Distant objects appear smaller, creating depth realism.
  • Viewing transformation: positions the camera/view reference frame and maps world geometry into the view coordinate system.
  • Projection transformation: maps 3D view coordinates onto a 2D projection plane.
  • Viewport transformation: maps normalized device coordinates to actual display coordinates.

17. Animation and Virtual Reality

Computer animation creates an illusion of movement by displaying a sequence of frames. Each frame may be generated by changing object transformations, camera position, lighting, material, shape or simulation state. The frame rate determines how frequently frames are displayed; motion blur and interpolation can improve perceived continuity.

  • Keyframe animation: animator defines important poses/time points; intermediate frames are generated by interpolation (tweening).
  • Path animation: object position/orientation is controlled along a predefined path.
  • Motion capture: records movement of a real performer and maps it to a digital character/object.
  • Virtual Reality: interactive computer-generated environment, often using a head-mounted display, motion tracking and spatial audio.
  • Augmented Reality: overlays digital objects/information onto a view of the real world. It is distinct from fully immersive VR.

18. Mobile Wireless Technologies and Network Types

  • Cellular network: divides a geographic region into cells, each served by radio access equipment. Frequency reuse increases capacity while requiring interference management.
  • Wi-Fi: wireless local-area networking, commonly based on IEEE 802.11 standards; it is not the same as cellular GSM/LTE.
  • Bluetooth: short-range wireless personal-area connectivity for peripherals and device-to-device links.
  • Satellite mobile communication: uses satellites for coverage over wide or remote areas; propagation delay and handover between satellite/terrestrial systems may matter.
  • Fixed wireless: wireless access where the subscriber equipment is generally installed at a fixed location. Mobile wireless supports movement while connected.

19. Mobile Computing Security and Quality of Service

  • Authentication: verifies the identity of a subscriber/device.
  • Confidentiality: prevents unauthorized parties from reading data, usually through encryption.
  • Integrity: detects unauthorized alteration of data.
  • Availability: keeps services accessible despite faults or attacks.
  • Quality of Service (QoS): describes service performance such as throughput, delay, jitter, packet loss and availability.
  • Roaming: allows a subscriber to use services outside the home operator's coverage area through agreements and network authentication/routing.
