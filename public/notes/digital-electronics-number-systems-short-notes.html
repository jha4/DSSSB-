Digital Electronics, Boolean Logic and Number Systems — Complete Notes

Coverage: Binary, octal, decimal and hexadecimal systems; complements and arithmetic; Boolean algebra; logic gates; K-maps; combinational and sequential circuits.

1. Number systems and representation

A number system represents quantities using symbols and a base (radix). In a positional system, each digit's value depends on its position: the weight of position i is base to the power i.

SystemBaseDigitsUse
Binary20, 1Digital representation
Octal80–7Compact binary grouping (3 bits)
Decimal100–9Human arithmetic
Hexadecimal160–9, A–FCompact binary grouping (4 bits)
  • To convert a positional number to decimal, expand each digit by its positional weight and add.
  • To convert a decimal integer to another base, repeatedly divide by the target base and read remainders bottom-to-top.
  • Binary-to-octal conversion groups bits in threes; binary-to-hexadecimal groups bits in fours.
  • A non-positional system does not assign value through positional weights in the same way; Roman numerals are a common example.

2. Complements and binary arithmetic

  • 1's complement: invert every bit. 2's complement: add 1 to the 1's complement; widely used for signed integers and subtraction.
  • Binary addition: 0+0=0, 0+1=1, 1+1=10, 1+1+1=11.
  • For n-bit 2's-complement values, the range is −2^(n−1) through 2^(n−1)−1. Unsigned n-bit values range from 0 through 2^n−1.
  • Signed overflow occurs when adding operands of the same sign produces a result with the opposite sign.

3. Boolean algebra and laws

Boolean algebra operates on binary variables using OR (+), AND (·) and NOT (complement).

LawIdentity
IdentityA+0=A; A·1=A
DominationA+1=1; A·0=0
IdempotentA+A=A; A·A=A
ComplementA+A'=1; A·A'=0
Involution(A')'=A
AbsorptionA+AB=A; A(A+B)=A

De Morgan's theorems: (A+B)'=A'B' and (AB)'=A'+B'. They are used to transform AND/OR logic into NAND/NOR forms.

4. Logic gates

  • AND: output 1 only when every input is 1. OR: output 1 when at least one input is 1. NOT: inverts an input.
  • NAND: complement of AND. NOR: complement of OR. Each is universal because any Boolean function can be implemented using only NANDs or only NORs.
  • XOR: output 1 when inputs differ. XNOR: output 1 when inputs are equal.

For two inputs: AND is 1 only for 11; OR is 0 only for 00; XOR is 1 for 01 and 10; XNOR is 1 for 00 and 11.

5. Canonical forms and K-maps

  • Minterm: product term containing every variable once; it is 1 for one input combination. Maxterm: sum term containing every variable once; it is 0 for one input combination.
  • SOP: sum of products. POS: product of sums.
  • Karnaugh map: Gray-code-ordered grid for grouping adjacent 1s (SOP) or 0s (POS). Groups contain 1, 2, 4, 8, ... cells; wrap-around adjacency is allowed.
  • Use the largest valid groups to eliminate the most variables. Don't-care cells may be used when they simplify the expression.

6. Combinational circuits

  • A combinational circuit has no stored state; output depends only on current inputs.
  • Half adder: Sum=A XOR B; Carry=AB. A full adder also accepts carry-in.
  • Multiplexer (MUX): selects one of many inputs for one output. n select lines can select 2^n inputs. A demultiplexer routes one input to one of many outputs.
  • Encoder: maps an active input to a code. Decoder: activates an output corresponding to an input code.

7. Sequential circuits and flip-flops

A sequential circuit has memory: output depends on current inputs and previous state. A latch is generally level-sensitive; a flip-flop is edge-triggered.

Flip-flopCharacteristic
SRSet/reset controls; one input combination may be invalid
JKJ=K=1 toggles
DNext state follows D at active clock edge
TT=1 toggles; T=0 holds
  • Register: group of flip-flops storing a multi-bit value. Shift registers move bits; SISO, SIPO, PISO and PIPO describe serial/parallel input and output.
  • Counter: sequential circuit advancing through a state sequence. Ripple counters propagate clock effects stage-by-stage; synchronous counters share a clock.
  • Multivibrator: astable has no stable state, monostable has one stable state and bistable has two stable states.

8. Exam traps

  • NAND and NOR are universal; XOR and XNOR are not universal by themselves.
  • A MUX selects; a decoder activates an output; an encoder produces a code.
  • Combinational circuits have no memory; sequential circuits do.
