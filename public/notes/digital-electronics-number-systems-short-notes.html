1. Number systems, complements and digital codes

A number system represents values using symbols and a radix (base). In positional notation, each digit is multiplied by a power of the base determined by its position.

SystemBaseSymbolsBinary grouping
Binary20, 1—
Octal80–73 bits
Decimal100–9—
Hexadecimal160–9, A–F4 bits
  • Base to decimal: expand using positional weights. (1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11₁₀.
  • Decimal integer to another base: repeatedly divide by target base and read remainders from bottom to top. 13₁₀ = 1101₂.
  • Binary to octal: group bits in threes from the binary point outward. 110101₂ = 65₈.
  • Binary to hexadecimal: group bits in fours. 11101101₂ = ED₁₆.
  • Fractions: repeatedly multiply the fractional part by the target base and read integer parts in order.
  • 1's complement: invert every bit. 2's complement: invert every bit and add 1.
  • Subtraction: A − B = A + (2's complement of B); discard final carry in fixed-width arithmetic.
  • Unsigned n-bit range: 0 to 2ⁿ−1. Two's-complement n-bit range: −2ⁿ⁻¹ to 2ⁿ⁻¹−1.
  • Signed overflow: occurs when two same-sign operands produce a result with the opposite sign.

BCD and Gray code

  • 8421 BCD: each decimal digit is encoded separately using four bits. Valid digit codes are 0000–1001; 1010–1111 are invalid.
  • BCD addition: add 0110 (decimal 6) if the 4-bit digit sum exceeds 1001 or produces a carry.
  • Gray code: adjacent code words differ in exactly one bit. Binary→Gray: copy the MSB; each next Gray bit is XOR of adjacent binary bits. Gray→binary: copy the MSB, then cumulatively XOR the previous binary bit with the current Gray bit.
  • Excess-3: add 3 to each decimal digit and encode the result in four-bit binary; it is non-weighted and self-complementing.
Exam trap: BCD encodes each decimal digit separately. Decimal 59 in BCD is 0101 1001, not its ordinary binary representation 0011 1011.

2. Boolean algebra and logic gates

Boolean algebra is the mathematical system used to analyse and simplify digital logic. Variables take only 0 or 1. Its basic operations are OR (+), AND (·) and NOT (complement).

LawIdentity
IdentityA+0=A; A·1=A
DominationA+1=1; A·0=0
IdempotentA+A=A; A·A=A
ComplementA+A'=1; A·A'=0
Involution(A')'=A
CommutativeA+B=B+A; AB=BA
Associative(A+B)+C=A+(B+C); (AB)C=A(BC)
DistributiveA(B+C)=AB+AC; A+BC=(A+B)(A+C)
AbsorptionA+AB=A; A(A+B)=A

De Morgan's theorems: (A+B)'=A'B' and (AB)'=A'+B'. Complement of a sum becomes product of complements; complement of a product becomes sum of complements. Duality: interchange + with · and 0 with 1.

  • AND: output 1 only when every input is 1; Y=AB.
  • OR: output 1 when at least one input is 1; Y=A+B.
  • NOT: inverts its input; Y=A'.
  • NAND: complement of AND; output 0 only when all inputs are 1; Y=(AB)'.
  • NOR: complement of OR; output 1 only when all inputs are 0; Y=(A+B)'.
  • XOR: output 1 when inputs differ; Y=A⊕B. XNOR: output 1 when inputs are equal; Y=(A⊕B)'.
  • Buffer: output equals input; used for signal restoration/drive.

Universal gates: NAND and NOR

A universal gate can implement NOT, AND, OR and therefore any Boolean function using that gate type alone.

FunctionNAND-only implementationNOR-only implementation
NOTA NAND A = A'A NOR A = A'
AND(A NAND B) NAND itself(A NOR A) NOR (B NOR B)
OR(A NAND A) NAND (B NAND B)(A NOR B) NOR itself
High-yield facts: NAND and NOR are universal. XOR=1 for unequal inputs; XNOR=1 for equal inputs. A⊕A=0; A NAND A=A'; A NOR A=A'.

3. Canonical forms and K-map simplification

  • Literal: a variable or its complement. Product term: AND of literals. Sum term: OR of literals.
  • Minterm: an AND term containing every variable once; it is 1 for exactly one input combination. A 0-valued variable is complemented.
  • Maxterm: an OR term containing every variable once; it is 0 for exactly one combination. A 0-valued variable is uncomplemented.
  • Canonical SOP: sum of minterms for which F=1, written Σm. Canonical POS: product of maxterms for which F=0, written ΠM.
  • Degree/order: number of distinct variables in a product term. A'B'C'D' has degree 4.

A Karnaugh map (K-map) is a Gray-code-ordered grid used to simplify Boolean expressions by grouping adjacent cells. An n-variable map contains 2ⁿ cells: 4 for two variables, 8 for three, 16 for four.

  • For SOP, group 1s; for POS, group 0s.
  • Groups contain powers of two cells: 1, 2, 4, 8, 16. Wrap-around adjacency is allowed, including opposite edges and corners.
  • Use the largest possible groups and cover every required cell. Overlapping groups are allowed when useful.
  • Variables that change within a group are eliminated; variables that remain constant form the simplified term.
  • Don't-care cells may be included if they simplify the result, or ignored.
Worked pattern: F(A,B,C)=Σm(0,2,5,7). Pair m0 with m2 to obtain A'C'; pair m5 with m7 to obtain AC. Therefore F=A'C'+AC.

4. Combinational and arithmetic circuits

A combinational circuit has outputs determined only by present input values. It has no stored state or memory.

CircuitInputsSumCarry
Half adderA, BS=A⊕BC=AB
Full adderA, B, CinS=A⊕B⊕CinCout=AB+ACin+BCin

A half adder adds two bits but has no carry-in. A full adder adds two data bits plus carry-in. An n-bit ripple adder commonly uses n full-adder stages (the least significant stage may be a half adder when Cin=0).

Adder-subtractor: XOR gates conditionally complement B. With mode M=0, B is unchanged and the circuit adds. With M=1, B is complemented and Cin=1, so it computes A+B'+1=A−B.

  • Multiplexer (MUX): data selector routing one of many input lines to one output. n select lines select 2ⁿ inputs; an 8:1 MUX needs 3 select lines.
  • Demultiplexer: routes one input to one of many outputs using select lines.
  • Encoder: converts one active input among 2ⁿ lines into an n-bit code. A priority encoder resolves multiple active inputs by priority.
  • Decoder: converts n input bits into up to 2ⁿ output lines, activating the output associated with the input code.
  • Comparator: indicates A>B, A=B or A<B. Parity generator/checker: uses XOR logic.
  • BCD adder: corrects a digit by adding 0110 if the binary sum exceeds 1001 or produces a carry.
Do not confuse: MUX selects; DEMUX distributes. Encoder produces a code; decoder activates an output. Counters and shift registers are sequential circuits.

5. Sequential circuits: flip-flops, counters and registers

A sequential circuit has memory; its output depends on current inputs and previously stored state. A latch is generally level-sensitive, while a flip-flop is generally edge-triggered. One flip-flop stores one bit.

Flip-flopBehaviour
SRSet, reset or hold; one input combination is invalid in the basic active-high NOR implementation.
JK00 hold; 01 reset; 10 set; 11 toggle. If J=K=1 it toggles.
DNext state follows D at the active clock edge.
TT=0 holds; T=1 toggles at the active clock edge.
  • Register: group of flip-flops storing a multi-bit word; n bits typically require n flip-flops.
  • Shift register: moves bits left or right. SISO=serial-in serial-out; SIPO=serial-in parallel-out; PISO=parallel-in serial-out; PIPO=parallel-in parallel-out.
  • Counter: advances through states on clock pulses/events. n flip-flops provide 2ⁿ states, normally 0 through 2ⁿ−1. MOD-N has N states.
  • Ripple/asynchronous counter: only the first flip-flop receives the external clock; following stages are clocked by preceding outputs, so delays accumulate.
  • Synchronous counter: all flip-flops receive a common clock.
  • Ring counter: last output feeds first input directly. Johnson/twisted-ring counter: complemented last-stage output feeds first input; n stages can produce up to 2n states.
  • Up/down counter: counts increasing/decreasing. Decade counter: MOD-10, normally 0 to 9. Cascaded independent MOD-6 and MOD-8 counters give MOD-48.

Multivibrators

TypeStable statesOperation
Astable0 stable; 2 quasi-stableFree-running oscillator; no external trigger required.

High-yield: T=1 toggles; T=0 holds. Astable has no stable state; monostable has one; bistable has two. Johnson counter uses complemented feedback.

6. Integrated circuits and logic families

An integrated circuit (IC) is a miniaturized electronic circuit fabricated on a semiconductor substrate. Integration categories include SSI, MSI, LSI and VLSI; exact gate ranges vary by textbook. The supplied PYQ uses 30–300 equivalent gates for MSI.

  • RTL: Resistor-Transistor Logic. DTL: Diode-Transistor Logic. TTL: Transistor-Transistor Logic.
  • ECL: Emitter-Coupled Logic; non-saturating bipolar logic, very fast and relatively high power.
  • CMOS: Complementary MOS; low static power and high input impedance.
  • Propagation delay: time between input transition and corresponding output response. tPLH is low-to-high; tPHL is high-to-low.
  • Power-delay product: power dissipation × propagation delay. Lower PDP generally indicates a better speed-power trade-off.
  • Fan-in: number of gate inputs. Fan-out: number of standard gate inputs an output can drive. Noise margin: tolerance to noise without changing logic interpretation.
